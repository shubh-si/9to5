Security & Trust

How we protect candidate personal data, secure uploaded resume documents, and ensure high-integrity hiring interactions across our infrastructure.

Data Encryption in Transit & Rest

All HTTP traffic is secured with TLS 1.3 encryption. Passwords are salted and hashed using PBKDF2/SHA256, and resume documents are stored in private encrypted storage buckets.

Role-Based Access Controls (RBAC)

Strict authorization checks ensure that candidate resumes and cover letters are only accessible to the applicant and the verified employer associated with that specific job.

CSRF & Injection Defenses

Every form submission and jQuery AJAX interaction is protected with anti-CSRF token verification, parameter sanitization, and parameterized ORM queries to prevent SQL and XSS vectors.

Verified Employer Moderation

Job postings undergo mandatory moderation review before publishing, protecting job seekers from recruitment scams, malicious links, and phishing attempts.

Responsible Vulnerability Disclosure

We appreciate the security community's efforts to help keep our platform safe. If you believe you have discovered a security vulnerability in JobPortal, please report it to our security team.
